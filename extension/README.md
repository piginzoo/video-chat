# 视频讲解器 · Chrome 插件

脚本跟随 × 双语字幕 × AI 对话 × 一键总结（YouTube / B站）。

## 安装（加载未打包扩展）

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车；
2. 右上角打开「开发者模式」；
3. 点「加载已解压的扩展程序」，选择本 `extension/` 目录；
4. 点击工具栏上的猪头图标（或 `chrome://extensions` 里该插件的图标），即可打开右侧侧边栏。

> 若插件安装前 YouTube/B站 页面已经打开，刷新一次该页面即可生效。

## 配置

打开侧边栏 → 「设置」Tab：

- 选择服务商（智谱 GLM / DeepSeek），粘贴 API Key，保存；
- 可点「⚡ 连通性测试」验证；
- GLM Coding Plan 套餐用户：Base URL 改为 `https://open.bigmodel.cn/api/coding/paas/v4`；
- Key 仅保存在浏览器本地（chrome.storage.local），不上传、不同步。

## 使用

- 打开任意 YouTube / B站 视频页，侧边栏自动识别并加载脚本（在其他页面打开侧边栏时，会自动挂载其他窗口里最近观看的视频）；
- YouTube 非中文字幕会自动批量翻译成双语对照（首次约 10~30 秒渐进完成，之后秒出）；
- 播放时脚本自动跟随高亮；手动滚动暂停 3 秒后恢复；点字幕行跳转视频；
- 「对话」Tab 针对视频内容提问，回答带可点击时间戳；GLM 推理模型的思考过程会以「💭 思考中…」形式实时展示；
- 悬浮按钮「✦ 总结」「🌳 视频结构」一键生成；
- 视频无字幕？两种兜底：**🎤 AI 听录**（下载音轨 → 智谱语音识别生成带时间戳脚本，全功能解锁；按量计费约 0.72 元/小时，需在设置页 ASR 区填 Key 并给账户充少量按量余额）或**粘贴脚本**（总结/对话可用，无跟随）；
- 有字幕的视频绝不会触发音轨下载，不花冤枉钱；
- 视频播完后 B站自动连播的下一个视频，侧边栏会自动跟着切换。

> 小知识：YouTube 播放器在暂停状态下不加载字幕数据。若打开页面后未播放，插件会静音快闪播放约 2.5 秒来触发字幕加载（时间点自动复原）；若仍未成功，你开始播放时会自动重试。

## 已知边界（v1）

- 仅支持 YouTube 标准 watch 页与 B站 `/video/` 页（不支持 Shorts、直播、番剧）；
- B站 AI 字幕需要浏览器内已登录 B站；
- YouTube 字幕抓取内置三层降级策略（ADR-003），极端情况下会提示使用粘贴兜底。
