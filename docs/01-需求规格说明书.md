# 视频讲解器 · 需求规格说明书

| | |
|---|---|
| 版本 | v1.0（2026-11-05） |
| 状态 | 待确认 |
| 产品形态 | Chrome 浏览器插件（Manifest V3，侧边栏 Side Panel） |
| 目标用户 | 通过 YouTube / B站 学习视频内容的中文用户 |

---

## 1. 产品定位

一个 Chrome 侧边栏插件：打开视频页面时，自动获取该视频的**字幕脚本**，提供三大能力——

1. **脚本跟随**：视频播到哪，脚本滚动到哪，双语对照阅读；
2. **AI 对话**：以整个视频内容为上下文，与脚本内容深入讨论；
3. **快捷洞察**：一键生成 300 字总结、一键生成视频结构树。

## 2. 支持范围

| 项目 | 范围 |
|---|---|
| 浏览器 | Chrome 114+（依赖 Side Panel API），v1 不承诺 Edge/Firefox |
| YouTube | `youtube.com/watch?v=*` 标准视频页 |
| B站 | `bilibili.com/video/*` 视频页（含分P，取当前分P） |
| 不支持 | B站番剧/影视/直播页、YouTube Shorts、嵌入式播放器、其他视频站 |

> 字幕获取抽象为「字幕提供方（Provider）」接口，为未来扩展其他站点预留，但 v1 仅实现以上两家。

**前置条件**

- B站 AI 字幕需要浏览器内已登录 B站账号（插件直接复用页面登录态，不处理登录流程）；
- 使用对话/总结/翻译功能需配置有效的 LLM API Key（DeepSeek 或智谱 GLM）。

## 3. 侧边栏整体结构

侧边栏固定三 Tab：**脚本**（默认）、**对话**、**设置**。

- **品牌 Logo 与版权**：侧边栏标题栏左侧展示用户的猪头 Logo（原图已提供，源文件 `assets/logo-original.jpg`，缩略图 `assets/logo-16/48/128.png`），同时用作插件图标（manifest 16/48/128px）。侧边栏底部常驻版权条（Logo + 「© 2026 piginzoo · 视频讲解器」），设置页「关于」区展示完整版权信息。
- **关闭按钮**：侧边栏标题栏右侧提供 ✕ 按钮，点击即可关闭侧边栏（无需去工具栏图标操作）。

- 打开侧边栏时自动检测当前激活标签页；是支持的视频页 → 自动加载该视频；不是 → 显示空态引导页（「请打开一个 YouTube 或 B站 视频页面」+ 支持站点说明）。
- **自动跟随**：侧边栏始终展示当前激活 tab 的视频。切换到另一个视频页时，自动重新加载该视频的数据；数据按视频 ID 隔离，切回原视频时其脚本与对话记录原样恢复。
- **跨窗口回退（v1.0.2 收窄）**：非视频页（含列表页/首页）激活时**一律显示空态，不抓取任何脚本**（用户反馈：列表页不应触发拉取）。唯一例外：激活标签页是插件自身页面（自动化/调试场景）时，回退到其他窗口最近活跃的视频页。视频页存在但桥接不上（插件比页面后安装）→ 显示「请刷新页面」提示态。
- 未配置 API Key 时：脚本跟随可用（不依赖 LLM，翻译除外）；对话/总结/结构树/翻译提示先去设置页配置。

## 4. Tab 1 · 脚本跟随

### 4.1 脚本获取

| 站点 | 优先级 | 说明 |
|---|---|---|
| YouTube | ① 人工上传字幕 → ② 自动生成字幕（ASR） | 用户可切换字幕轨道（多语言轨道时提供轨道选择器） |
| B站 | ① UP 主上传 CC 字幕 → ② AI 字幕（需登录态） | 多轨道时同样提供选择器 |

- 每条字幕为一个「行」：时间点 + 原文。
- 脚本加载后自动开始**双语预翻译**（见 4.3）。
- 顶部展示视频标题、时长、脚本行数、翻译进度。

### 4.2 跟随交互（全套标准交互）

1. **自动跟随**：播放时自动滚动到当前行并高亮；
2. **手动暂停**：用户手动滚动脚本区时暂停自动跟随，停止操作约 3 秒后恢复；
3. **点击跳转**：点击任意字幕行 → 视频 seek 到该行起始时间；
4. **当前行高亮**：明显视觉标识当前播放位置。

### 4.3 双语翻译

- 触发条件：脚本语言**非中文**（如 YouTube 英文视频）。B站中文视频不触发。
- 方式：加载完成后将**整篇脚本分块批量交给 LLM 翻译**，流式返回、逐行填充到界面（非逐句实时翻译，避免播放期间持续请求）。
- 展示：中文译文显示在英文原文下方（弱化样式），双语对照。
- 缓存：翻译结果按「视频 ID + 字幕轨道」缓存本地，二次打开秒出。
- 提供翻译显示开关（仅原文 / 双语）。

### 4.4 无字幕兜底

视频无可用字幕时，提供两种补救方式：

1. **🎤 AI 听录（v1.1 新增，推荐）**：一键下载视频音轨 → 智谱 GLM-ASR 语音识别 → 生成带时间戳的脚本 → **跟随、跳转、翻译、总结、对话全功能解锁**，与官方字幕无差别。按量计费（约 0.72 元/小时），结果本地缓存（二次打开零成本）。限制：≤60 分钟视频；纯音乐可能无文本；处理时间约为视频时长的 1~5%。
2. **粘贴脚本**：把别处的脚本/字幕文本粘贴进来——总结、结构树、对话可用（无时间轴，跟随与跳转不可用）。

> 有字幕的视频**永远不会**触发音轨下载与识别（代码路径级保证，避免浪费费用）。ASR 配置位于设置页独立区域（API Key / Base URL / 模型名 + 连通性测试）。
>
> **无字幕检测结果缓存 30 天**（用户反馈）：检测过无字幕的视频，期间打开直接出听录/粘贴卡片、不再重复请求；30 天后自动重检一次（B站 AI 字幕/YouTube 字幕可能后补）；卡片提供手动「🔄 重新检测字幕」按钮。

## 5. Tab 2 · 设置

### 5.1 双套配置 + 切换

DeepSeek 与智谱 GLM 各保存一套配置，顶部单选切换当前生效的服务商：

| 字段 | DeepSeek 默认值 | 智谱 GLM 默认值 | 可改 |
|---|---|---|---|
| API Key | 空 | 空 | ✓（掩码显示，可切换明文） |
| Base URL | `https://api.deepseek.com` | `https://open.bigmodel.cn/api/paas/v4` | ✓（支持中转/代理） |
| 模型名 | `deepseek-chat` | `glm-5.3-flash` | ✓（自由填写） |

> 若使用**智谱 GLM Coding Plan** 套餐，GLM 的 Base URL 需改为 Coding Plan 专用端点 `https://open.bigmodel.cn/api/coding/paas/v4`；普通 API Key 使用官方默认地址。设置页在 GLM Base URL 下方提供此提示文案。

### 5.2 其他要求

- **存储**：`chrome.storage.local`（浏览器本地，不进代码仓库、不云同步、网页脚本不可读），满足「不暴露」要求；
- **连通性测试按钮**：保存后可一键发送测试请求，验证 Key/URL/模型可用性，显示成功/失败原因；
- 配置错误（未配置/请求失败）在对话等入口处给出明确引导。

## 6. Tab 3 · 对话

### 6.1 上下文策略

- 首次进入对话，自动构造上下文：视频标题 / 作者 / 时长 + **完整脚本**（含时间戳标记）+ 粘贴脚本（如有）；
- **全文推送**：每轮对话均携带完整脚本；
- **超长截断**：脚本估算 token 超出模型安全窗口时截断并在界面提示「脚本过长，已截断后半部分」。

### 6.2 对话行为

- **流式输出**：回答打字机式逐字显示；
- **时间戳引用**：提示词要求模型在引用脚本处标注 `[mm:ss]`，前端渲染为可点击链接，点击后视频 seek 到该时间；
- **语言**：模型默认以中文回答；
- **历史持久化**：对话按视频 ID 存本地，重开同一视频自动恢复；提供「清空本视频对话」按钮；
- 总结/结构树的输出同样作为消息留存于对话流。

### 6.3 悬浮快捷按钮（2 个）

固定悬浮于输入框上方：

| 按钮 | 行为 | 输出约束 |
|---|---|---|
| **总结** | 以「300 字讲清楚这个视频讲了什么」为指令发起请求 | ≤300 字，中文 |
| **视频结构** | 生成视频内容结构树 | 仿 Linux `tree` 命令的纯文本层级缩进格式，≤500 字，中文 |

输出以 assistant 消息流式呈现在对话流中。

## 7. 非功能需求

### 7.1 安全与隐私

- API Key 仅存 `chrome.storage.local`，界面掩码显示；
- 脚本/对话内容仅发送到**用户配置的 LLM 端点**，不经过任何其他服务器；
- 无遥测、无数据采集。

### 7.2 性能

| 指标 | 目标 |
|---|---|
| 字幕抓取 | 打开侧边栏后 ≤3 秒出脚本 |
| 翻译 | 1 小时视频脚本约 10~30 秒渐进完成（流式填充） |
| 对话 | 首字延迟取决于服务商，流式即时呈现 |
| 跟随滚动 | 与播放进度同步延迟 ≤0.5 秒 |

### 7.3 费用透明

- 翻译、对话均消耗所配置服务商的 token；1 小时视频脚本量级约数万 token，费用极低（DeepSeek 约几分钱人民币，GLM flash 档免费）；
- 设置页显示当前服务商与模型，用户可自选更低价模型。

## 8. 边界与异常处理

| 场景 | 行为 |
|---|---|
| 非视频页打开侧边栏 | 空态引导页 |
| 视频无字幕 | 提示 + 粘贴脚本入口（§4.4） |
| B站 AI 字幕但未登录 B站 | 提示「登录 B站后可获取 AI 字幕」，仍可走粘贴兜底 |
| LLM 请求失败/超时 | 错误消息显示失败原因（网络/鉴权/限流区分），可重试 |
| API Key 未配置 | 功能入口提示并引导到设置页 |
| 视频页内切集/切P | 自动识别视频 ID 变化，重新加载对应数据 |
| 翻译中断（关侧边栏） | 已翻译部分保留，重新打开时从断点续翻或重翻（实现取简单者） |

## 10. v1 明确不做（Out of Scope）

- ASR 语音转文字兜底（无字幕视频的自动化方案，留待 v2 评估）；
- 除 YouTube / B站外的其他视频站；
- 逐句精读模式（只显示当前行前后 N 行）；
- 笔记导出、收藏、跨设备同步；
- 界面多语言（v1 仅中文 UI）。

## 11. 验收标准（测试阶段照此执行）

1. 打开一个带字幕的 YouTube 英文视频 → 脚本加载、双语渐进填充、播放跟随滚动高亮、点击行跳转、手动滚动暂停后恢复；
2. 打开一个 B站视频 → 脚本加载、跟随正常（无需翻译）；
3. 配置 GLM（临时测试 Key + Coding Plan 端点 + `glm-5.3-flash`）→ 连通性测试通过；对话/总结/结构树/翻译全链路用该模型验证。测试 Key 不写入任何源码与文档，测试完成后由用户吊销；
4. 对话 Tab：发起提问 → 流式中文回答、含可点击 `[mm:ss]`、点击后视频跳转；换视频后对话隔离；重开同视频历史恢复；
5. 悬浮按钮「总结」→ ≤300 字中文总结流式输出；「视频结构」→ tree 风格结构树 ≤500 字；
6. 打开非视频页 → 空态引导页；无字幕视频 → 粘贴兜底可用；
7. 重启浏览器 → API Key 保留、脚本翻译缓存生效（秒出）。
