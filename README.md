# 视频讲解器 🐷

> 看 YouTube / B站 视频，右侧永远蹲着一只猪：帮你把视频"变成一篇可以对话的文档"。

**视频讲解器**是一个 Chrome 浏览器插件（侧边栏形态）。你打开一个视频，它自动把字幕脚本抓下来；视频播到哪，脚本就跟到哪；看不懂的地方直接问，AI 拿着整个脚本来回答你；一键生成 300 字总结和结构树；视频没字幕？它还能把音轨扒下来用 AI 听录出一份带时间戳的脚本。

做这个项目的起因很简单：看技术视频、长访谈、纪录片的时候，来回拖进度条找"他说过的一句关键的话"太痛苦了。有了它，视频变成了可以**搜索、可以提问、可以精读**的东西。

---

## 它能干什么

### 📜 脚本跟随（核心功能）
- 自动抓取当前视频的完整字幕脚本，**视频播到哪、脚本滚到哪、当前句高亮**；
- 点脚本任意一句 → 视频跳到那句话；
- 手动滚动脚本时自动暂停跟随，3 秒后恢复，不打扰你自由阅读。

### 🌏 双语字幕
- YouTube 英文视频自动把整篇脚本翻译成中文，**英文原文 + 中文译文逐行对照**；
- 翻译结果本地缓存，第二次打开秒出。

### 💬 跟视频对话
- AI 拿着**完整脚本**回答你的问题，不是泛泛而谈，是真读过这个视频；
- 回答里引用内容会带 `[03:24]` 这样的时间戳，**点一下视频就跳过去**；
- 每个视频的对话独立保存，下次打开接着聊。

### ✨ 一键洞察
- **总结**：300 字讲清这个视频讲了什么；
- **视频结构**：仿 `tree` 命令的内容结构树，一眼看懂视频脉络。

### 🎤 无字幕？AI 听录
- 遇到没有字幕的视频（B站大量视频、部分中文 YouTube 频道），点一下「AI 听录」：
- 插件把音轨扒下来、切片、用智谱语音识别生成**带时间戳的完整脚本**；
- 转写结果本地缓存，一次付费永久使用；
- 有字幕的视频绝不会触发听录（不花冤枉钱）。

### 🔒 隐私
- API Key、脚本缓存、对话记录全部只存在你浏览器本地（`chrome.storage.local`）；
- 视频内容只发给你自己配置的 AI 服务商，无遥测、无数据采集、无中间服务器。

## 安装（3 步，不用打包）

1. 下载/克隆本仓库，拿到 `extension/` 目录；
2. Chrome 打开 `chrome://extensions` → 右上角开「开发者模式」→ 点「加载已解压的扩展程序」→ 选 `extension/` 目录；
3. 点工具栏上的 🐷 图标，侧边栏就出来了。

> 要求 Chrome 114 或更高版本（侧边栏 API）。已开着的视频页刷新一下即可生效。

## 配置 AI

打开侧边栏 → 「设置」：

**LLM 服务商**（对话 / 翻译 / 总结用），二选一填 Key，随时切换：
- 智谱 GLM：默认 `glm-5.3-flash`（也可以用 [Coding Plan](https://open.bigmodel.cn) 的 Key，Base URL 改成 `https://open.bigmodel.cn/api/coding/paas/v4`）；
- DeepSeek：默认 `deepseek-chat`（非推理模型，对话首字更快）。

**ASR 语音识别**（只有无字幕视频听录时才用）：
- 填智谱 API Key + 给账户充少量按量余额（与 Coding Plan 额度分开计费）；
- 价格约 **0.72 元/小时**音频，一次听录通常只要几毛钱；
- 结果本地缓存，绝不重复识别。

> 所有 Key 都有「连通性测试」按钮，填完点一下就知道通不通。

## 使用速查

| 想做什么 | 怎么做 |
|---|---|
| 看脚本 | 打开视频，侧边栏自动加载 |
| 跳到某句话 | 点脚本里那句 |
| 问视频内容 | 「对话」Tab 直接问 |
| 跳到 AI 提到的位置 | 点回答里的 `[mm:ss]` |
| 快速了解视频 | 点「✦ 总结」 |
| 看视频脉络 | 点「🌳 视频结构」 |
| 无字幕视频 | 点「🎤 AI 听录生成字幕」或粘贴脚本 |
| 关闭侧边栏 | 点侧边栏右上角 ✕，或再点工具栏图标 |

## 已知限制（诚实版）

- 只支持 YouTube 标准视频页和 B站视频页（不支持 Shorts、直播、番剧）；
- B站 AI 字幕需要你已登录 B站；部分视频（时政类等）平台不生成 AI 字幕；
- YouTube 无字幕视频的 AI 听录采用"静音播放 + 实时录制音轨"方案，耗时约等于视频时长（期间你可以正常观看，画面不受影响）；
- AI 听录暂不支持超过 60 分钟的视频；
- 无字幕检测结果会缓存 30 天（期间不重复检测），卡片上有手动「重新检测」按钮。

## 是怎么做的（给感兴趣的同学）

- Chrome Manifest V3，原生 HTML/CSS/JS，**零构建、零第三方依赖**；
- YouTube 字幕抓取内置四层降级策略（页面直拉 → 播放器拦截 → InnerTube → 文字记录面板），2025 年后 YouTube 封锁了字幕直链，这套组合拳是实测能打的那套；
- B站走官方 API 双轨制（CC 字幕优先、AI 字幕兜底），复用浏览器登录态；
- 批量翻译流水线：分块、并发 2、断点续翻、本地缓存；
- 无字幕听录：B站下载 dash 音轨（offscreen 解码切片），YouTube 实时捕获音轨（SABR 时代没有音频直链，这是实测可行的方案）；
- 完整的设计决策和踩坑记录都在 [`docs/`](docs/) 里——包括需求规格、可交互原型、以及一份写得很诚实的 [ADR 架构文档](docs/03-系统架构设计.md)（里面记录了每一个实测推翻的假设）。

```
extension/
├── manifest.json          # MV3
├── background.js          # Service Worker（极薄）
├── content/               # YouTube / B站 页面脚本（字幕抓取、进度上报）
├── sidepanel/             # 侧边栏 UI（三 Tab：脚本 / 对话 / 设置）
└── offscreen/             # 音频解码（AI 听录用）

docs/
├── 01-需求规格说明书.md
├── 02-交互原型.html       # 浏览器直接打开，可交互
└── 03-系统架构设计.md
```

## 隐私与安全

- **不采集任何数据**，没有服务器，一切发生在你的浏览器里；
- API Key 存本地、界面掩码显示，仓库里没有任何密钥；
- 脚本/对话内容仅发送到你配置的 AI 服务商（智谱 / DeepSeek）。
